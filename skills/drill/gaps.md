# Gap kinds

Run every new statement through each kind. `bin/whys kinds` adds kinds learned from the miss log.

- reference: An external reference ("like X", "per the rulebook", "the usual way"). List what it concretely implies; owner confirms or rejects each item.
- edge-case: Unusual or boundary situations. What happens when it is empty, tied, first, last, or simultaneous?
- limits: Scale, counts, sizes, ranges, speed, time spans.
- interaction: How it affects or depends on other statements.
- output: What the owner sees: screens, text, files, numbers, ordering, wording.
- failure: What happens when it goes wrong, is invalid, or is interrupted.
- existing: What already exists that this touches, replaces, or must stay compatible with.
